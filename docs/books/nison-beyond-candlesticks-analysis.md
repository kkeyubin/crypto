# 《日本蜡烛图技术新解》分析报告

## 来源与提取质量

- 作者：史蒂夫·尼森（Steve Nison）
- 英文书名：*Beyond Candlesticks: New Japanese Charting Techniques Revealed*
- 结构：上篇蜡烛图、下篇差异指数与新价图，共 8 章
- EPUB 提取结果：约 97,000 个中文字符、48 个正文条目、294 张图片
- 限制：本报告依据正文与图注；尚未逐张视觉核验行情图。涉及画线示例或图中相对位置的结论必须标记为“需要图像核验”。

## 作者的核心框架

1. **整体技术面优先**：孤立的蜡烛图形态不是交易指令。必须同时考虑趋势、支撑阻力、形态所处位置和风险收益比。（第4章）
2. **顺势使用反转信号**：上升趋势中的多头形态用于入场，空头形态优先用于保护或平多；下降趋势反之。（第4章“趋势”）
3. **收盘确认优先**：支撑阻力是否被突破、新价图是否反转，原则上以对应周期的收盘价确认。（第2、4、6～8章）
4. **信号与执行分离**：蜡烛图擅长提示反转或持续，但通常不提供目标价；目标位应来自支撑阻力、趋势线等其他方法。（第4章“风险与收益的权衡”）
5. **确认存在代价**：多等一个确认信号会降低误判概率，也会牺牲入场价格和潜在收益。（第6、8章）
6. **市场失效即改变观点**：建立交易前先定义哪个价格会证明判断错误，触发后停止坚持原观点。（第4章“做一个市场变色龙”）

## 风险管理与反模式

- 入场前必须同时给出止损与目标位；风险收益不合适时，即使形态标准也应放弃。
- 止损通常放在形态所形成的支撑或阻力之外，并按相应周期收盘确认；具体执行仍需考虑跳空和滑点。
- 不要把每个十字星、锤子线或吞噬形态直接变成订单。
- 不要用书中某张图的差异指数阈值、砖值或钥匙图转向值套用所有市场。
- 不要只报告最优参数；敏感度越高，信号越多、横盘反复越严重。
- 新价图忽略时间并过滤小波动，适合抓趋势主体，不适合宣称精确抄底逃顶。

## 对加密货币研究的初步判断

本书可用于加密货币，因为核心输入仍是 OHLC 或收盘价，且市场可双向交易。但 24/7 交易会让“日线开盘”和传统市场跳空的含义发生变化；窗口类形态在连续交易市场中可能稀少或机制不同。回测时应固定交易所、现货或永续、K 线时区，并加入手续费、滑点和资金费率。

最适合第一轮回测的不是“全部蜡烛图大全”，而是规则最明确的三组：三线反向突破、砖形图、钥匙图；随后再把锤子线、吞噬等作为同趋势入场过滤器。
