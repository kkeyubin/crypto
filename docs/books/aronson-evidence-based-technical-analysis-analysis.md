# 《Evidence-Based Technical Analysis》拆解分析

## 书籍定位

- **作者**：David R. Aronson
- **主题**：用科学方法、统计推断和数据挖掘偏差校正评估技术交易信号
- **结构**：9 章；第 1–7 章建立方法论、心理学、哲学与统计基础，第 8–9 章以 6,402 条 S&P 500 规则做案例研究
- **本项目用途**：为后续加密货币策略提供研究治理框架，而不是直接提供可交易信号

## 核心结论

Aronson 的中心主张是：技术分析只有在规则可重复、命题可证伪、数据可追溯、推断考虑抽样误差和数据挖掘偏差时，才可能形成知识。盈利回测只是必要条件，不是预测力的充分证据。

最重要的实践转化是把策略研究分为两层：

1. **发现层**：提出指标、枚举规则、优化参数；
2. **证据层**：用与整个搜索过程匹配的基准、抽样分布和样本外数据判断结果是否超出运气。

不能用“单个规则事先固定”的显著性检验，去评价“从数千规则中事后挑出的赢家”。

## 作者的核心框架

### 1. Evidence-Based Technical Analysis（EBTA）

EBTA 只接受有认知内容的命题，例如“规则 X 在预先定义的持有期内产生正的期望超额收益”。预测必须让真与假产生可辨识差异。含糊的趋势线、事后解释和无法复现的形态不构成可检验知识。

### 2. 客观规则是输入—变换—输出系统

规则必须明确：输入数据、数学/逻辑算子、参数、阈值、输出状态和执行时点。输出可以是 `long/short`、`long/neutral`、`short/neutral` 或 `long/neutral/short`。强迫策略持续持仓可能歪曲原始交易思想，因此状态空间也是待证明的假设。

### 3. 相对基准评价，而非看绝对收益

规则收益同时受规则的多空仓位偏置与市场净趋势影响。在长期上涨样本中，长期偏多的随机规则也可能赚钱。作者用去趋势收益消除这种混淆，并证明它等价于扣除“具有相同仓位偏置的无预测力规则”的期望收益。

### 4. 可证伪优先于寻找确认案例

科学检验采用“如果假设成立，则应观察到某结果；结果未出现，因此假设被否证”的逻辑。观察到相符结果只能让假设暂时存活，不能证明它为真。策略报告应优先列出失效证据和替代解释，而不是精选成功交易。

### 5. 统计推断是从样本到总体的受控外推

研究必须明确总体、样本、总体参数、样本统计量、抽样方法和抽样分布。`p-value` 是在零假设成立时，得到至少同样极端统计量的概率；它不是“策略为假的概率”。拒绝或保留 `H0` 都可能犯错，需同时管理 I 类错误、II 类错误和检验功效。

### 6. Bootstrap 与 Monte Carlo permutation

- **Bootstrap**：对规则收益有放回重采样，估计统计量的抽样分布；评价单规则时通常先零中心化。
- **Monte Carlo permutation（MCP）**：无放回打乱规则输出与未来市场收益的配对，检验规则输出是否比随机配对包含更多预测信息。
- 两者检验的零假设不完全相同。普通版本只适用于事先固定的单规则；数据挖掘后的赢家需要联合校正。

### 7. Data-Mining Bias（数据挖掘偏差）

观察表现可拆为：

```text
observed performance = expected performance ± randomness
```

搜索过程必然选择观察表现最高者，因此赢家通常同时吸收了最大正向运气。偏差大小受五项因素决定：

1. 测试规则越多，偏差越大；
2. 观测数越多，偏差越小；
3. 规则收益相关性越低，有效搜索空间越大，偏差越大；
4. 正向极端收益越强，偏差通常越大；
5. 候选规则真实期望收益越接近，偏差越大。

### 8. 三类偏差解决方案

- **样本外 / walk-forward**：在训练窗口发现规则，只在未参与选择的数据上评价；测试集使用一次后不再“纯净”。
- **White’s Reality Check（WRC）**：保存所有候选规则的逐期收益，通过联合 bootstrap 构造“无效规则宇宙中最大均值”的抽样分布。
- **多规则 MCP**：保存全部规则输出，并在每次置换中对所有规则使用同一收益排列，以保留规则间相关结构，再记录每次最大表现。

Markowitz–Xu 收缩法可作粗略检查，但作者明确指出它在一些常见条件下可能严重失真。

## 案例研究的关键证据

作者在去趋势的 S&P 500 数据上测试 6,402 条简单多空反转规则。最佳规则的年化均值为 10.25%。如果错误地按单规则检验，其 `p-value=0.0005`；在 0.05 阈值下约有 320 条规则会显得显著，恰好接近纯随机情况下的预期数量。

考虑完整搜索后：

- WRC：`p=0.8164`
- MCP：`p=0.8194`
- 结论：没有规则足以拒绝“所有规则均无预测力”的零假设

该例最有价值之处不是“这些规则失败”，而是同一观察收益在错误与正确抽样分布下会得到完全相反的结论。对 6,402 个无效候选，最佳规则的零假设抽样分布中心约为 11%，而不是 0%。

## 转化为加密策略研究规范

### 研究登记

在读取测试结果前固定：交易所、现货/永续、标的、K 线边界、数据版本、样本区间、信号公式、参数宇宙、持仓状态、执行延迟、成本模型、绩效统计量和零假设。

### 搜索账本

保存所有尝试过的规则，而不只是最终赢家。至少保存：规则 ID、参数、逐期输出、逐期净收益、交易次数、失败状态和代码版本。未记录的人工试错也属于搜索次数。

### 正确评价顺序

1. 检查数据泄漏与时间对齐；
2. 选择合理基准；
3. 报告成本前与成本后表现；
4. 先用与搜索规模匹配的联合检验；
5. 再看冻结规则的独立样本外与 walk-forward 表现；
6. 报告置信区间、回撤、换手和经济意义；
7. 未通过时保留失败结果，不重新定义成功标准。

### 加密市场特有补充

原书使用股票指数日线，迁移到加密市场时还必须处理 24/7 K 线边界、不同交易所价格源、永续资金费率、费率层级、滑点、爆仓/保证金约束、合约上市与退市、数据断点和市场制度漂移。这些是基于作者原则的项目化扩展，不应归为原书原话。

## 反模式

- 看到漂亮权益曲线后才决定规则定义或样本起点；
- 只报告最佳参数，隐去参数网格和失败实验；
- 用单规则 `p<0.05` 评价从大规模搜索中选出的赢家；
- 用本根收盘生成信号，却假定按同一收盘价成交；
- 在上涨市场中用零收益而非仓位偏置基准评价长期偏多规则；
- 反复查看测试集并继续调整，却仍称其为样本外；
- 把统计显著等同于扣除成本后的可交易性；
- 以市场变化解释所有失败，从而让策略永远不可证伪。

## 与后续书籍的组合价值

这本书将成为多书综合 Skill 的“证据与研究治理层”。尼森和 Volman 提供形态、背景与执行候选；Aronson 决定这些候选如何客观化、如何记录搜索空间，以及什么证据才允许我们说策略可能具有预测力。

## 局限

本书出版于 2007 年，未覆盖现代金融机器学习中的 purged/embargo cross-validation、deflated Sharpe ratio、probability of backtest overfitting 等后续工具，也未涉及加密永续合约。其方法论仍然适用，但具体推断实现需结合现代时间序列统计和本项目的数据生成过程。
