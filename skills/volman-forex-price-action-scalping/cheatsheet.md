# Decision Cheatsheet

## Setup Identification

| Question | If yes | If no |
|---|---|---|
| Is price in a trend pullback? | Test DD/FB/SB | Test BB/RB/IRB/ARB |
| Is this the first substantial pullback after a forceful new surge? | FB | Continue |
| Did a first with-trend attack already fail to continue? | SB | DD or no trade |
| Is there only a compact box? | BB, subject to context | Continue |
| Is price still inside a larger range? | RB at edge; IRB within it | Continue |
| Is price already outside a broken range? | ARB | Reassess |

## Mandatory Vetoes

- No identifiable directional pressure.
- Target path is blocked or too short.
- Signal line was defined only after the outcome.
- Breakout is anticipated rather than observed.
- RB has no buildup at the boundary.
- Stop, target, or intrabar collision rule is unspecified.
- Estimated costs consume the plausible edge.
