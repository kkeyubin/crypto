# Operational Patterns

## Context Before Setup

```text
pressure identified -> target space measured -> obstacles checked
-> setup allowed or vetoed -> signal line frozen -> breakout observed
```

Pattern geometry never overrides an unfavorable market.

## DD

```text
trend/new trend -> orderly 40–60% pullback -> 2+ adjacent small bars
-> choose furthest trend-side extreme -> break with trend
```

## FB

```text
fast one-way surge, preferably from consolidation
-> first substantial 40–60% pullback -> first bar taken out with trend
```

## SB

```text
trend -> pullback -> first with-trend break lacks follow-through
-> renewed counterpressure -> second with-trend break
```

SB counts attempts, not candle count.

## BB

```text
compact box with repeated top/bottom touches
-> directional pressure selects one side -> that side breaks
```

A break on the unfavorable side is not automatically a reverse trade.

## RB

```text
mature horizontal range -> price approaches one boundary
-> small bars compress against it -> original boundary breaks
```

Reject a direct cross from the opposite side (false break) and a weak premature poke (tease).

## IRB

```text
wide established range -> small block inside range
-> upper-area downside break toward lower edge
or lower-area upside break toward upper edge
or BB-like break in a spacious middle
```

IRB usually exploits movement *inside* the range. It is not merely an early external-breakout entry.

## ARB

```text
old range already broken
-> (A) cluster holds outside boundary and forms a new signal line
or (B) pullback tests converted boundary and turns back
-> new outside-range trigger breaks
```

## Tipping-Point Trail

```text
initial structural invalidation -> trade advances -> new completed structure
-> tighten invalidation toward target -> scratch if crossed
```

Never loosen the level. Freeze update timing so later price cannot retroactively change it.

## Scale Translation

For every original pip threshold, register several independent candidates such as exchange ticks, basis points, and rolling median true range. Select them only through a declared training procedure and evaluate once on untouched data.
