# Chapter 1: 概述

## Core Idea

蜡烛图不是孤立的买卖系统，而是一种把开盘、最高、最低、收盘及多空力量可视化的市场语言。本书在蜡烛图之外，引入差异指数、三线反向突破图、砖形图和钥匙图，用趋势工具补足蜡烛图不擅长给出目标位和大势方向的问题。

## Frameworks Introduced

- **蜡烛图作为择时工具**
  - When to use: 已经有趋势、支撑阻力或其他市场背景时。
  - How: 用实体、影线和组合形态观察力量变化，再用后续价格确认。
- **日本技术与西方技术结合**
  - When to use: 需要把反转预警、趋势判断、目标位和风险控制组成完整交易流程时。
  - How: 蜡烛图负责信号与时机，趋势线、均线、支撑阻力或新价图负责背景与退出。
- **新价图**
  - When to use: 希望过滤细小波动、只用收盘价观察趋势主体时。
  - How: 仅在价格满足创新高、创新低或预设反转幅度时更新图形。

## Key Concepts

- **OHLC**: 蜡烛线由开盘价、最高价、最低价和收盘价构成。
- **力量变化**: 实体与影线用于观察多空哪一方控制当前周期。
- **新价图**: 忽略或弱化时间，只在价格满足条件时添线。
- **三线反向突破图**: 用最近同色线的极值确认趋势转向。
- **砖形图**: 用固定价格单位过滤不足一砖的波动。
- **钥匙图**: 用转向值、方向及阴阳粗细记录趋势变化。

## Mental Models

- 把蜡烛图看作市场地图，而不是自动下单器。
- 用多个互补工具解决不同问题，不要求单一指标同时负责趋势、入场、止损和目标。
- 任何反转形态都必须先有可供反转的趋势。

## Anti-patterns

- **形态名称即交易指令**: 名称识别没有纳入趋势、位置和风险。
- **把本书当完整K线词典**: 本书是进阶与扩展，不覆盖所有蜡烛图形态。
- **认为新工具可以精确抄底逃顶**: 新价图刻意牺牲早期价格以换取过滤和确认。

## Worked Example

当三线反向突破图确认多头趋势后，只响应同方向的多头蜡烛图信号；逆向空头信号首先用于减仓、保护或等待，而不是自动反手。这样把“大势判断”和“入场择时”分离。

## Key Takeaways

1. 蜡烛图的价值在于增添力量维度，而不是替代全部技术分析。
2. 新价图更适合判断趋势主体和退出，不追求顶底。
3. 策略应明确每种工具承担的单一职责。
4. 后续量化必须把视觉术语转成可复现阈值。
