# Chapter 5: 日本人如何使用移动平均线

## Core Idea

移动平均线既可确认趋势，也可把价格相对均线的位置量化为差异指数或偏离指数。极端值不是自动反转信号，应与市场自身历史和蜡烛图确认结合。

## Frameworks Introduced

- **黄金交叉与死亡交叉**
  - When to use: 用两条不同周期均线判断中长期方向。
  - How: 短期均线上穿长期均线为黄金交叉；下穿为死亡交叉。
- **差异指数（差异比率）**
  - When to use: 判断价格相对均线的超买超卖、趋势方向或背离。
  - How: `(Close - MA_n) / MA_n × 100%`。
- **偏离指数**
  - When to use: 与差异指数相同，但希望以相对比例表达。
  - How: `Close / MA_n × 100%`；偏离指数102%等价于差异指数+2%。
- **极端环境 + 蜡烛图确认**
  - When to use: 差异指数进入该资产历史极端区时。
  - How: 等待十字星、锤子、吞噬、乌云盖顶等同方向证据，或用极端状态过滤逆向入场。
- **差异指数背离**
  - When to use: 价格创新高/低而差异指数未同步时。
  - How: 比较相邻价格极值和指数极值，作为动能衰减预警。

## Key Concepts

- **短线均线示例**: 5日、9日、25日。
- **长线均线示例**: 13周、26周、75日、200日。
- **超买/超卖阈值**: 必须按资产、周期和均线长度校准。
- **背离**: 价格与差异指数极值方向不一致。
- **箱体震荡**: 横盘可通过时间而非反向价格缓解极端状态。

## Mental Models

- 把差异指数当环境变量，不把它当单独的反转按钮。
- 参数示例是研究起点，不是跨市场常数。
- 极端状态表示延续概率下降，不代表反转必须立即发生。

## Anti-patterns

- **套用±10%或±15%到所有资产**: 书中数值来自特定图表。
- **只优化均线周期**: 大量尝试后选最好结果会制造回测过拟合。
- **超买立即做空、超卖立即做多**: 强趋势可以长时间维持极端。

## Reference Tables

| 工具 | 公式/规则 | 用途 |
|---|---|---|
| 差异指数 | `(C - MA_n) / MA_n × 100` | 极端、趋势斜率、背离 |
| 偏离指数 | `C / MA_n × 100` | 与差异指数等价的另一表达 |
| 黄金交叉 | `MA_short` 上穿 `MA_long` | 多头趋势信号 |
| 死亡交叉 | `MA_short` 下穿 `MA_long` | 空头趋势信号 |

## Worked Example

某书中股票的13周差异指数在约+10%与-10%附近表现为极端，但另一个市场示例使用约±15%。正确研究方式是先固定训练区间和分位数/阈值生成方法，再在样本外检验；不能在完整历史上观察峰谷后倒推阈值。

## Key Takeaways

1. 差异指数和偏离指数信息等价。
2. 极端阈值必须按市场和周期预先校准。
3. 差异指数适合做背景过滤和确认，不宜孤立使用。
4. 回测必须记录尝试过的全部均线和阈值组合。
