# Chapter 4: 蜡烛图与市场的整体技术面

## Core Idea

市场整体状况比孤立形态更重要。完整决策必须包含趋势背景、信号位置、止损、目标位、风险收益比和明确的观点失效条件。

## Frameworks Introduced

- **止损作为判断失效点**
  - When to use: 每次建立仓位之前。
  - How: 先说明哪个价格行为会证明判断错误；通常把止损放在形态压力或支撑之外，并按相应周期收盘确认。
- **风险与收益权衡**
  - When to use: 形态完成但尚未下单时。
  - How: 用形态或支撑阻力定义风险，用趋势线、前高低、窗口等定义目标；不诱人就跳过。
- **顺趋势交易**
  - When to use: 市场已有明确上升或下降趋势时。
  - How: 同向信号用于开仓，逆向信号优先用于平仓、减仓或保护。
- **市场变色龙**
  - When to use: 交易后市场未按预期发展。
  - How: 预先记录阻力/支撑和时间窗口；一旦被收盘突破，改变观点而不是辩护。
- **计算机筛选而非计算机裁决**
  - When to use: 程序化识别蜡烛图。
  - How: 让程序找候选，再用趋势、位置、风险收益和非标准但有上下文的证据筛选。

## Key Concepts

- **风险**: 入场到失效/止损之间的潜在损失。
- **潜在收益**: 入场到合理目标位之间的距离。
- **技术汇合**: 多个独立工具在相近区域指向相同判断。
- **形态区域**: 压力或支撑通常是区间，不只是单一点。
- **观点失效**: 市场达到预先定义的价格，证明原假设不再成立。

## Mental Models

- 把交易当成有失效条件的假设，而不是必须被市场证明正确的观点。
- 好形态不等于好交易；入场位置决定风险收益。
- 顺势信号用于进攻，逆势信号先用于防守。

## Anti-patterns

- **形态一完成就下单**: 没有计算风险、目标和空间。
- **用程序机械排除所有非标准形态**: 可能错过重要位置上的力量变化；但人工例外必须留痕，不能事后美化。
- **没有止损的自动策略**: 与作者的风险管理原则直接冲突。
- **市场反证后继续坚持**: 把预测变成信念。

## Reference Tables

| 决策问题 | 必须回答的内容 |
|---|---|
| 趋势是什么 | 趋势线、均线或新价图的客观状态 |
| 信号在哪里 | 是否接近支撑、阻力、窗口、前高低 |
| 判断何时错误 | 明确价格、收盘周期和执行动作 |
| 收益来自哪里 | 可解释的目标位，不用愿望代替 |
| 值得交易吗 | 预先规定最低风险收益要求 |

## Worked Example

书中启明星示例在1205附近完成，合理目标约1220，而形态低点约1169。潜在收益约15、风险约36，即便这是标准多头形态，也应放弃。关键不是后来是否上涨，而是决策时这笔交易不符合资金管理原则。

## Key Takeaways

1. 形态只是候选信号，风险收益决定是否执行。
2. 蜡烛图通常不负责给目标位，必须组合其他工具。
3. 每笔交易先定义失效价和确认周期。
4. 自动化必须保留上下文过滤和完整审计轨迹。
5. 事后盈利不能证明当时决策合理。
