# Chapter 3: 蜡烛图组合形态

## Core Idea

蜡烛图形态提供近期力量变化和反转预警。有效使用需要三个层次：形态定义、此前趋势、后续确认；形态还可形成支撑或阻力，为失效点提供依据。

## Frameworks Introduced

- **锤子线与吊颈线**
  - When to use: 锤子线必须在明显下跌或超卖环境后；吊颈线必须在上涨后。
  - How: 小实体位于区间上端，下影通常至少为实体3倍，上影很短或没有；吊颈线需下一周期收盘低于其实体确认。
- **流星线**
  - When to use: 上涨趋势后的顶部预警。
  - How: 小实体接近区间底部、长上影；结合阻力和后续弱势确认。
- **乌云盖顶与刺穿形态**
  - When to use: 上涨后的空头反转、下跌后的多头反转。
  - How: 乌云盖顶第二根黑线标准上需收进前白实体中点以下；刺穿形态第二根白线需收至前黑实体中点或以上。
- **吞噬与包孕**
  - When to use: 趋势末端观察控制权转换或波动收缩。
  - How: 吞噬比较实体包覆关系；包孕是长实体内部出现小实体，表示趋势动能变化。
- **窗口**
  - When to use: 识别持续信号及后续支撑阻力。
  - How: 上升窗口作为潜在支撑，下降窗口作为潜在阻力；关闭窗口意味着原趋势力量减弱。
- **启明星与黄昏星**
  - When to use: 下跌后的三线底部反转或上涨后的三线顶部反转。
  - How: 长实体、分离的小实体、反向长实体依次表达原趋势、犹豫、控制权转换。

## Key Concepts

- **确认**: 形态后出现与其方向一致的收盘或实体。
- **合成蜡烛线**: 用首根开盘、组合最高最低、末根收盘把多根线压缩为一根。
- **最后吞噬顶/底**: 外观类似相反方向吞噬，但因所处趋势不同而重新解释。
- **迭创新高（低）**: 8～10个连续或近似连续新高/低是过热或过冷预警。
- **弹簧线/上插线**: 暂时突破支撑/阻力后重新收回，表示假突破。

## Mental Models

- 先问“此前有什么趋势”，再问“这是什么形态”。
- 形态高低点不仅用于命名，也用于止损和支撑阻力。
- 确认越多，误判可能越低，但入场越晚。

## Anti-patterns

- **锤子形状到处做多**: 没有显著下跌背景就不是有效锤子反转。
- **吊颈线未确认即做空**: 长下影本身仍显示买盘，需要后续弱收盘。
- **窗口在连续市场照搬**: 加密货币24/7交易中传统跳空较少，必须先验证形成机制和样本数。
- **把预警当确定反转**: 迭创新高/低、十字星、高浪线只提示关注。

## Reference Tables

| 形态 | 必要背景 | 定义锚点 | 确认/失效参考 |
|---|---|---|---|
| 锤子线 | 下跌趋势 | 下影通常≥实体3倍，小实体在上端 | 低点下方收盘失效；可等待回测支撑 |
| 吊颈线 | 上涨趋势 | 与锤子同形 | 下一周期收盘低于实体确认 |
| 乌云盖顶 | 上涨趋势 | 黑线深入前白实体，标准为中点以下 | 形态高点上方失效 |
| 刺穿形态 | 下跌趋势 | 白线收至前黑实体中点或以上 | 形态低点下方失效 |
| 多头吞噬 | 下跌趋势 | 白实体包住前黑实体 | 组合低点作为支撑候选 |
| 空头吞噬 | 上涨趋势 | 黑实体包住前白实体 | 组合高点作为阻力候选 |

## Worked Example

锤子线出现后，激进交易者可先建立小仓；若后续回落但守住锤子低点形成的支撑，再加仓。保守版本等待支撑测试成功后才入场。两种版本必须分别回测，不能在看到结果后选择更有利的一种。

## Key Takeaways

1. 形态定义、趋势背景和确认是不可拆开的三部分。
2. 形态的交易价值经常来自与支撑阻力的汇合。
3. 预警、确认、入场和失效应在策略规格中分开。
4. 视觉化术语需要预先注册数值定义。
