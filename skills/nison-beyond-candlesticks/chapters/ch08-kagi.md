# Chapter 8: 钥匙图

## Core Idea

钥匙图使用预设转向值决定换向，并用突破前高或前低改变线的粗细（阳/阴），从而同时表达趋势方向、结构高低点和力量变化。

## Frameworks Introduced

- **转向值换向**
  - When to use: 从收盘序列构造钥匙线。
  - How: 价格沿原方向继续时延长；反向移动达到固定值或百分比后，右移一格反向延伸。
- **见阳买入、见阴卖出**
  - When to use: 基础趋势策略。
  - How: 上破前高时由细变粗（阴转阳）为买入；下破前低时由粗变细（阳转阴）为卖出。
- **肩与腰**
  - When to use: 观察结构趋势。
  - How: 前高称肩、前低称腰；肩腰同步抬高表示强势，同步降低表示弱势。
- **多级突破确认**
  - When to use: 希望降低一级突破假信号。
  - How: 等待突破两个或三个此前肩/腰，再确认趋势改变。
- **长线中点**
  - When to use: 评估修正是否破坏原趋势。
  - How: 上涨后的修正守住长钥匙线中点偏强；下跌后的反弹未越中点偏弱。
- **双窗口与三佛形态**
  - When to use: 识别钥匙图上的底部、顶部和头肩结构。
  - How: 比较肩腰相对位置，并用一级/多级突破确认。

## Key Concepts

- **转向值**: 触发方向改变的绝对值或百分比。
- **阳线/阴线**: 钥匙图的粗线/细线，不等同于蜡烛颜色。
- **拐点线**: 相反方向钥匙线之间的短横连接。
- **肩/腰**: 前高/前低。
- **多级突破**: 突破多个历史肩或腰后的加强确认。
- **迭创新高（低）**: 约9个肩或腰依次创新高/低后的反向风险预警。

## Mental Models

- 转向值控制噪声，肩腰结构控制趋势解释，阴阳转换控制基础交易状态。
- 百分比转向值能随价格水平缩放，但仍需按市场验证。
- 越多级确认越稳健，也越迟。

## Anti-patterns

- **把3%或5%当通用最优值**: 书中只是常见实践和示例。
- **把粗细误当涨跌方向**: 方向与阴阳粗细是两个维度。
- **忽略价格尺度变化**: 长历史中固定绝对值可能前后含义不同。
- **横盘机械反转**: 趋势不明确时会高买低卖。

## Reference Tables

| 事件 | 钥匙图变化 | 基础解释 |
|---|---|---|
| 沿原方向继续 | 延长当前线 | 趋势延续 |
| 反向达到转向值 | 右移并反向延长 | 出现修正/转向 |
| 向上突破前高 | 阴转阳、线变粗 | 买入/强势信号 |
| 向下突破前低 | 阳转阴、线变细 | 卖出/弱势信号 |
| 肩腰同步抬高 | 结构上行 | 多头占优 |
| 肩腰同步降低 | 结构下行 | 空头占优 |

## Worked Example

3%钥匙图在价格50时转向值为1.5，价格升至70时转向值变为2.1。实现时必须明确百分比以哪个锚点重算、何时更新，以及跨越多重结构边界时的事件顺序，否则不同实现会产生不同信号。

## Key Takeaways

1. 钥匙图比砖形图表达更多结构，但实现也更复杂。
2. 必须分别建模方向、转向和阴阳转换。
3. 多级突破是确认参数，不应事后选择。
4. 百分比转向更适合跨价格尺度，但仍需滚动验证。
5. 钥匙图适合趋势主体，不适合宣称精准顶底。
