# Chapter 2: 基本知识

## Core Idea

单根蜡烛线的实体、影线和相对位置可以揭示多空力量、犹豫以及潜在支撑阻力，但信号价值取决于此前趋势和后续确认。

## Frameworks Introduced

- **长实体作为力量与价格区域**
  - When to use: 判断突破力度、支撑或阻力。
  - How: 长白实体反映买方控制，长黑实体反映卖方控制；实体中点至极值可成为后续价格区域。
- **影线作为价格拒绝**
  - When to use: 判断市场是否拒绝高价或低价。
  - How: 长上影表示高价遭拒，长下影表示低价遭拒；结合趋势和位置解释。
- **十字星与高浪线作为过渡状态**
  - When to use: 延伸趋势后观察动能衰减。
  - How: 等待下一至两个周期确认方向，并用形态高低点定义失效。
- **收盘突破确认**
  - When to use: 判断支撑阻力是否真正失效。
  - How: 以相应图表周期的收盘价越界为确认，不只看盘中刺穿。

## Key Concepts

- **实体**: 开盘与收盘之间的区间。
- **影线**: 实体之外到最高、最低价的线段。
- **长白蜡烛线**: 开盘接近低点、收盘接近高点，实体通常至少为近期实体的约3倍。
- **长黑蜡烛线**: 开盘接近高点、收盘接近低点，实体通常至少为近期实体的约3倍。
- **十字星**: 开盘与收盘相同或非常接近，表示犹豫。
- **高浪线**: 上下影线都长，表示强烈争夺和方向不确定。
- **极性转换**: 旧支撑被突破后可能成为阻力，旧阻力被突破后可能成为支撑。

## Mental Models

- 用实体读控制权，用影线读拒绝，用上下文判断意义。
- 同一形状在上涨后和下跌后的含义可能相反。
- 盘中越界是测试，收盘越界才是作者偏好的确认。

## Anti-patterns

- **固定像素识别“长”**: 应相对近期实体或波动尺度定义。
- **中继区十字星即反转**: 没有延伸趋势时，十字星通常缺乏指令意义。
- **忽略周期**: 日线、周线的收盘确认不能混用。

## Reference Tables

| 形态 | 作者给出的可编码锚点 | 常见用途 |
|---|---|---|
| 长白实体 | 实体约为近期实体的3倍或以上 | 确认支撑、向上突破、形成支撑区 |
| 长黑实体 | 实体约为近期实体的3倍或以上 | 确认阻力、向下突破、形成阻力区 |
| 十字星 | 开盘约等于收盘 | 趋势延伸后的犹豫与反转预警 |
| 高浪线 | 上下影均长 | 趋势进入中性或过渡状态 |

## Worked Example

如果某周价格盘中跌破长白实体形成的支撑、但周五重新收回支撑上方，作者仍把支撑视为有效；只有周收盘落在其下方，才确认突破。这一规则在回测中要求信号使用本周期收盘，订单最早在下一可成交时点执行。

## Key Takeaways

1. 实体和影线是力量信息，不是脱离背景的预测。
2. “长”“短”“接近”必须在代码中明确定义。
3. 支撑阻力区比单一精确价位更符合作者表达。
4. 收盘确认可减少假突破，但会增加延迟。
