# Chapter 7: 砖形图

## Core Idea

砖形图只在收盘价移动达到固定砖值时增加等高砖块，忽略不足一砖的变动。白砖和黑砖构成最基础的趋势买卖信号，代价是在横盘中容易反复进出。

## Frameworks Introduced

- **固定砖值过滤**
  - When to use: 希望忽略小于指定价格幅度的噪声。
  - How: 先确定砖值；沿当前方向每移动满一个砖值就增加一砖，余数不显示。
- **反向砖信号**
  - When to use: 判断趋势方向切换。
  - How: 白砖出现作为买入/多头状态，黑砖出现作为卖出/空头状态。
- **趋势主体捕捉**
  - When to use: 市场有较持续方向时。
  - How: 接受较迟的反向信号，持续持有直至颜色反转。

## Key Concepts

- **砖值**: 每块砖代表的固定价格变动。
- **白砖**: 上行砖。
- **黑砖**: 下行砖。
- **多砖更新**: 一个周期跨越多个砖值时应添加多块砖。
- **余数**: 不足一砖的价格移动不反映在图上。

## Mental Models

- 用价格位移而不是钟表时间定义信息。
- 砖越大，噪声越少、信号越晚；砖越小，信号越多、横盘损耗越大。
- 砖形图适合趋势跟随，不承担顶底预测。

## Anti-patterns

- **把书中1、2、3、5美元砖值当通用参数**: 都是示例或特定市场设置。
- **忽略同柱多砖路径**: 只有OHLC时，无法总是知道周期内先触及哪个方向。
- **在整段历史上优化砖值**: 会把未来波动信息泄漏到参数选择。
- **忽略横盘交易成本**: 频繁颜色切换会放大手续费和滑点。

## Reference Tables

| 条件 | 图形动作 | 策略含义 |
|---|---|---|
| 收盘沿上行方向每增加一砖值 | 添白砖 | 维持/进入多头状态 |
| 收盘沿下行方向每减少一砖值 | 添黑砖 | 维持/进入空头状态 |
| 价格移动不足一砖 | 不更新 | 过滤噪声 |
| 横盘反复跨砖 | 颜色频繁变化 | 趋势策略高风险环境 |

## Worked Example

在5点砖形图中，若最后白砖高点为145，后续收盘升至158，只能确认两块完整新砖，155到158的3点余数不显示。此后需要到达下一完整砖边界才继续添砖。实现必须明确边界包含关系和浮点取整方式。

## Key Takeaways

1. 砖形图规则简单，但砖值选择决定大部分行为。
2. 回测要处理单柱跨多砖和执行价格。
3. 横盘是主要失败模式，费用建模不可省略。
4. 参数应在训练窗口确定并滚动验证。
