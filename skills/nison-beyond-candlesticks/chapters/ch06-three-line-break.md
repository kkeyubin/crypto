# Chapter 6: 三线反向突破图

## Core Idea

三线反向突破图只使用收盘价，只在价格创新高/低时添线，并用突破最近三根连续同色线的极值确认反转。它过滤小波动、反应较慢，目标是抓住趋势主体。

## Frameworks Introduced

- **新高新低添线**
  - When to use: 从收盘序列构造三线反向突破状态。
  - How: 收盘高于当前前高画白线，低于当前前低画黑线；区间内不画。
- **三线反向突破**
  - When to use: 已有至少三根连续同色线时判断反转。
  - How: 跌破最近三根连续白线的最低点画黑色转向线；突破最近三根连续黑线的最高点画白色转向线。
- **趋势过滤 + 蜡烛图择时**
  - When to use: 希望减少逆势K线交易。
  - How: 白色趋势只响应多头K线入场，黑色趋势只响应空头K线入场；逆向信号用于退出。
- **多一线确认**
  - When to use: 希望减少转向线假信号。
  - How: 转向线后再等待一根同色线；接受更迟入场。
- **敏感度调整**
  - When to use: 匹配短线或长线研究。
  - How: 二线更敏感，五线或十线更平滑；三线是书中最常用的基准。

## Key Concepts

- **白线**: 收盘创新高形成的上升线。
- **黑线**: 收盘创新低形成的下降线。
- **转向线**: 突破最近三根反向同色线极值的线。
- **黑鞋/白套装/脖颈**: 小黑线、白色转向线及其后的短白线组成的确认语言。
- **迭创新高（低）**: 8～10根连续或近似连续同色线提示过热或过冷。

## Mental Models

- 宁可放弃头尾，也要交易趋势中段。
- 没有新增极值就没有新信息，不让时间本身制造信号。
- 更高确认度以更低潜在利润为代价。

## Anti-patterns

- **用盘中极值代替收盘价构图**: 违背本书基本定义。
- **同一收盘既生成信号又按该收盘成交**: 回测会产生不可实现的同柱成交偏差。
- **只展示最佳突破线数**: 二、三、五、十线都试过时必须计入多重测试。
- **横盘频繁反手**: 趋势工具在无趋势环境会反复亏损。

## Reference Tables

| 状态 | 新收盘条件 | 动作 |
|---|---|---|
| 少于三根连续同色线 | 高于当前高点 | 新白线 |
| 少于三根连续同色线 | 低于当前低点 | 新黑线 |
| 至少三根连续白线 | 低于最近三根白线最低点 | 黑色转向线 |
| 至少三根连续黑线 | 高于最近三根黑线最高点 | 白色转向线 |
| 未越过相关边界 | 区间内部 | 不添线 |

## Worked Example

若最近三根黑线的最高点为31，盘中上破31但收盘为30.5，则白色转向线未确认。严格版本不入场；试探版本可盘中轻仓，但收盘未确认时必须退出。若收盘33确认转向，回测最早应按下一可成交价格执行，或明确建模盘中触发与失败退出。

## Key Takeaways

1. 构图只依赖收盘价，规则高度可编码。
2. 三线突破用于趋势方向，蜡烛图用于同向择时。
3. 转向确认会延迟，但这是设计目标而非缺陷。
4. 首轮应以三线为基准，其他线数作为预注册稳健性测试。
