# Glossary

**包孕形态** — 长实体之后出现完全位于其实体内部的小实体，表示动能收缩或过渡（Ch 3）。

**差异指数（差异比率）** — `(收盘价 - 移动平均) / 移动平均 × 100%`，用于描述超买超卖、趋势和背离（Ch 5）。

**长白蜡烛线** — 开盘接近低点、收盘接近高点且实体显著较长；作者给出实体约为近期实体3倍或以上的锚点（Ch 2）。

**长黑蜡烛线** — 开盘接近高点、收盘接近低点且实体显著较长；可确认阻力或向下突破（Ch 2）。

**吊颈线** — 上升趋势后的锤子状线，需要下一周期收盘低于其小实体确认空头意义（Ch 3）。

**高浪线** — 上下影线都长，表示多空强烈争夺和方向不确定（Ch 2）。

**黄金交叉** — 短期移动平均线上穿长期移动平均线（Ch 5）。

**极性转换** — 旧阻力突破后可能成为支撑，旧支撑突破后可能成为阻力（Ch 2, Ch 4）。

**肩 / 腰** — 钥匙图中的前高 / 前低（Ch 8）。

**流星线** — 上升趋势后出现的小实体、长上影线顶部预警形态（Ch 3）。

**偏离指数** — `收盘价 / 移动平均 × 100%`；102%等价于差异指数+2%（Ch 5）。

**启明星** — 下跌趋势中的三线底部反转结构：原趋势长黑、分离的小实体、深入第一实体的长白（Ch 3）。

**三线反向突破图** — 只用收盘价，在突破最近三根连续反向同色线极值时确认转向的新价图（Ch 6）。

**十字星** — 开盘与收盘相同或很接近，表示犹豫；趋势延伸后才更有反转预警意义（Ch 2）。

**死亡交叉** — 短期移动平均线下穿长期移动平均线（Ch 5）。

**吞噬形态** — 趋势末端第二根实体包住第一根反向实体的双线形态（Ch 3）。

**乌云盖顶** — 上升趋势中，第二根黑线高开后深入前白实体；标准形态收至其中点以下（Ch 3）。

**新价图** — 只有价格满足创新高、创新低或反转幅度时才更新、弱化时间因素的图形（Ch 1, Ch 6–8）。

**钥匙图（Kagi）** — 以转向值换向、以前高前低突破改变阴阳粗细的价格图（Ch 8）。

**迭创新高（低）** — 8～10次连续或近似连续新高/低形成的过热/过冷预警（Ch 3, Ch 6, Ch 8）。

**影线** — 实体外连接最高价或最低价的线段；长影线表达对相应价格区域的拒绝（Ch 2）。

**阴线 / 阳线（钥匙图）** — 钥匙图的细线 / 粗线，由跌破前低或突破前高触发，不等同于蜡烛颜色（Ch 8）。

**转向线** — 三线反向突破图中越过最近三根相反同色线极值的反向线（Ch 6）。

**砖形图（Renko）** — 以固定砖值增加等高白砖或黑砖、过滤不足一砖波动的价格图（Ch 7）。

**锤子线** — 下跌趋势后出现、小实体位于区间上端、下影通常至少为实体3倍的底部反转候选（Ch 3）。
