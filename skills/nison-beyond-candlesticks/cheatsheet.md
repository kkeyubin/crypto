# Decision Cheatsheet

## 信号处理顺序

| 步骤 | 问题 | 不满足时 |
|---|---|---|
| 1 | 此前是否有明确趋势？ | 不把反转形态当交易信号 |
| 2 | 信号是否处于有意义的位置？ | 降级为观察项 |
| 3 | 是否已按对应周期收盘确认？ | 等待，不提前使用未来收盘 |
| 4 | 失效价在哪里？ | 不建仓 |
| 5 | 目标位依据是什么？ | 不用愿望估收益 |
| 6 | 风险收益是否达到预注册门槛？ | 放弃交易 |
| 7 | 成交成本后仍成立吗？ | 放弃或重新研究 |

## 工具选择

| 需求 | 优先工具 | 原因 |
|---|---|---|
| 观察短期力量变化 | 蜡烛图 | OHLC与影线信息最丰富 |
| 判断收盘价趋势 | 三线反向突破 | 无需固定价格反转值 |
| 过滤固定幅度噪声 | 砖形图 | 规则简单、砖块等高 |
| 观察结构高低点和力量 | 钥匙图 | 肩腰、阴阳、多级突破 |
| 量化价格相对均线位置 | 差异/偏离指数 | 公式明确 |

## 可编码阈值与非通用参数

- 锤子/吊颈：下影通常不小于实体约3倍；仍需定义趋势、小实体、短上影。
- 长白/长黑：实体约为近期实体3倍或以上；需定义“近期”统计窗口。
- 乌云盖顶：标准为第二根黑线收在前白实体中点以下。
- 刺穿形态：第二根白线收在前黑实体中点或以上。
- 迭创新高/低：8～10次是预警，不是独立订单。
- 差异指数±10%/±15%、Renko砖值、Kagi 3%/5%均为示例，不能跨市场直接套用。

## 新价图确认权衡

- 更敏感：信号早、数量多、横盘损耗大。
- 更迟钝：信号晚、数量少、抓趋势主体。
- 多一线/多一级确认：降低误判可能，同时降低潜在利润。

## 回测防错

- 信号使用本周期收盘时，成交不得假设发生在同一收盘之前。
- 固定交易所、产品、周期和K线时区。
- 永续合约加入手续费、滑点和资金费率。
- 记录所有参数组合，不只展示赢家。
- 参数在训练窗口确定，样本外和滚动窗口验证。
- 24/7加密市场中的窗口/跳空信号单独统计，不默认与传统市场等价。
