# Glossary

**Alternative hypothesis (H1)** — 与零假设互斥、研究者希望获得支持的总体参数主张。（Ch 5）

**Benchmark** — 用于判断规则表现是否超出无预测力或现有替代方案的比较标准。（Ch 1）

**Bootstrap** — 从原样本有放回重采样以估计统计量抽样分布的方法。（Ch 5–6）

**Cognitive content** — 一个命题的真假能够产生可辨识差异，因而可以接受经验检验。（Introduction, Ch 2–3）

**Confidence interval** — 按给定覆盖率构造、用于表达总体参数不确定范围的区间程序。（Ch 5）

**Data-mining bias** — 从多个候选中选择最佳观察表现，使赢家表现系统性高估其期望表现。（Ch 6）

**Data snooping** — 使用同一数据或既往研究结果反复决定测试内容，却未将这些选择计入搜索过程。（Ch 6, 9）

**Detrending** — 从每期市场收益扣除样本均值，移除市场净趋势对规则评价的影响。（Ch 1, Appendix）

**Evidence-Based Technical Analysis (EBTA)** — 仅以客观规则、可证伪命题和统计推断形成技术分析知识的方法。（Introduction）

**Expected performance** — 规则总体分布的理论表现；不同于一次样本中的观察表现。（Ch 6）

**Falsification** — 由假设推出预测，再用未出现的预测结果有效否证假设。（Ch 3）

**Look-ahead bias** — 回测在某时点使用当时尚不可得的信息或价格。（Ch 1）

**Monte Carlo permutation (MCP)** — 通过无放回打乱规则输出与未来市场收益的配对构造零假设分布。（Ch 5–6）

**Null hypothesis (H0)** — 默认保留、通常表示规则无预测力或期望收益不大于基准的主张。（Ch 5）

**Objective rule** — 对相同输入总产生相同输出、可由明确数学和逻辑算子实现的规则。（Ch 1）

**Observed performance** — 规则在特定历史样本中的表现，由期望表现和随机成分共同构成。（Ch 6）

**p-value** — 在 H0 成立时得到至少同样极端检验统计量的概率。（Ch 5）

**Position bias** — 规则处于多头、空头或中性状态的长期比例偏置。（Ch 1）

**Power** — 当备择假设真实时正确拒绝 H0 的概率。（Ch 5）

**Sampling distribution** — 在重复抽样下某个样本统计量可能取值的概率分布。（Ch 4–5）

**Subjective TA** — 依赖分析者私人解释、无法稳定复现和客观反驳的技术分析。（Ch 2）

**Type I error** — H0 为真却错误拒绝它；假阳性。（Ch 5）

**Type II error** — H0 为假却未能拒绝它；假阴性。（Ch 5）

**Walk-forward testing** — 在滚动窗口中只用训练段选择规则，并在随后的非重叠测试段评价。（Ch 6）

**White's Reality Check (WRC)** — 对全部候选规则逐期收益做联合 bootstrap，评价数据挖掘赢家显著性的程序。（Ch 6）
