# EBTA Cheatsheet

## 研究放行顺序

| Gate | 必须回答 | 不通过时 |
|---|---|---|
| 命题 | 真与假会产生什么可辨识差异？ | 不回测 |
| 规则 | 输入、参数、输出和成交是否唯一？ | 继续客观化 |
| 时间 | 信号数据在成交前是否真实可得？ | 修正滞后 |
| 基准 | 规则要击败什么无预测力/替代方案？ | 重定义超额收益 |
| 搜索 | 实际测试和人工查看了多少候选？ | 补全搜索账本 |
| 推断 | 抽样分布是否重放完整选择过程？ | 不接受 p 值 |
| 样本外 | 规则是否在查看测试结果前冻结？ | 降级为训练结果 |
| 可交易 | 成本、滑点、容量和风险后仍有意义？ | 不进入实盘 |

## 单规则还是搜索后赢家

| 情况 | 适用统计量 |
|---|---|
| 事前固定一条规则 | 单规则 mean/Sharpe 的抽样分布 |
| N 条中选择最佳 | N 条统计量最大值的联合分布 |
| 查看结果后改参数 | 所有查看过的版本都属于 N |
| 引用既往成功规则 | 将先前搜索视为潜在 data snooping |

## 数据挖掘偏差快判

```text
规则更多        -> 偏差更大
观测更多        -> 偏差更小
规则相关更低    -> 有效搜索空间更大 -> 偏差更大
正向异常值更强  -> 偏差通常更大
真实质量更接近  -> 赢家更依赖运气 -> 偏差更大
```

## 推断方法选择

| 目标 | 首选 | 关键保存内容 |
|---|---|---|
| 单规则均值 | bootstrap / permutation | 逐期规则收益或输出 |
| 搜索后最佳规则 | WRC / 多规则 MCP | 全部候选的逐期记录 |
| 冻结规则未来表现 | untouched holdout | 锁定代码、参数、数据快照 |
| 非平稳适应 | walk-forward | 每个 fold 的训练与测试日志 |
| 粗略偏差敏感性 | Markowitz–Xu | 全部规则收益；不可作主证据 |

## 加密市场附加字段

- 交易所、现货/永续、合约生命周期
- UTC 与 K 线边界、缺失/重复 K 线
- 手续费层级、点差、滑点、资金费率
- 最小下单量、保证金、杠杆与爆仓
- 市场制度与流动性分层

这些字段是项目扩展，不是原书专门讨论的内容。
