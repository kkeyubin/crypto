# Chapter 3: The Scientific Method and Technical Analysis

## Core Idea

科学方法不是证明喜欢的规则为真，而是提出有认知内容的假设、演绎可反驳预测、用未知结果的数据进行严格检验，并让暂时存活的解释继续面对更强反证。

## Frameworks Introduced

- **Hypothetico-deductive method**
  - When to use: 从观察到的市场规律形成研究计划。
  - How: 提出 `X predicts Y`；演绎“若 X 真能预测 Y，未来未观察样本中的 X 应被 Y 跟随”；固定检验；根据结果否证或暂时保留。
- **Falsification of the consequent**
  - When to use: 判断证据是否能有效推翻假设。
  - How: `If H then E; not E; therefore not H`。
- **Conjectures and refutations**
  - When to use: 管理策略迭代。
  - How: 允许创造性提出候选，但把验证资源用于主动寻找候选失败的环境。
- **Discernible-difference test**
  - When to use: 判断主张是否值得检验。
  - How: 说明主张为真和为假会分别观察到什么；若所有结果均兼容主张，则其为空命题。

## Key Concepts

- **Deduction**: 若前提真且形式有效，结论必真。
- **Induction**: 从有限观察外推一般规律，结论只能是概率性的。
- **Affirming the consequent**: `If H then E; E; therefore H`，这是无效推理，因为其他假设也可能产生 E。
- **Hasty generalization**: 用少量成功信号推断普遍预测力。
- **Occam's razor**: 在解释力相当时偏好更简单、可检验的理论。
- **Provisional knowledge**: 以现有证据获得合理支持，但持续开放修正。

## Worked Example

假设 `H` 为“规则 X 有预测力”，预测 `E` 为“冻结规则后，在新样本中平均超额收益为正”。若新样本没有出现 E，H 受到否证。若出现 E，不能从 `If H then E; E` 推出 H 必真，因为风险暴露、市场趋势、成本漏计或数据泄漏也可能产生 E。研究必须排除替代解释并继续复制。

## Why It Works / Failure Mode

该方法把创意和裁决分离：创意可以自由，裁决必须受逻辑和未知结果约束。失败发生在研究者查看数据后不断重写 H 或 E，使任何结果都能得到解释；此时假设失去可证伪性。

## Anti-patterns

- **将确认证据当充分证明**: 一致结果可能有多个原因。
- **用同一观察提出并确认假设**: 探索数据不能同时充当独立确认。
- **预测失败后改变含义**: 让主张永远无法被推翻。
- **少数交易案例外推**: 犯草率归纳。

## Key Takeaways

1. 科学是错误探测器，不是绝对真理探测器。
2. 假设必须先于确认数据冻结。
3. 反证在逻辑上比相符案例更有区分力。
4. 市场知识天然不确定且暂时有效。
5. 策略研究应保存未通过检验的候选。
