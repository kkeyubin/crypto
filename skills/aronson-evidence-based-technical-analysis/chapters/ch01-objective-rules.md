# Chapter 1: Objective Rules and Their Evaluation

## Core Idea

技术规则只有在相同输入产生相同输出时，才可被回测和证伪；评价规则必须剥离市场趋势、仓位偏置、未来信息和不可实现成交造成的假表现。

## Frameworks Introduced

- **Objective versus subjective acid test**
  - When to use: 判断一个形态或判断法能否进入研究流程。
  - How: 让不同分析者对同一数据独立执行；若输出不一致且规则未规定如何消解差异，它仍是主观方法。
- **Rule as a transformation function**
  - When to use: 编码技术信号。
  - How: 定义输入时间序列、数学/逻辑算子、自由参数、阈值与输出市场状态。
- **Position-bias benchmark**
  - When to use: 规则多空比例不平衡且样本市场有趋势。
  - How: 比较具有相同仓位偏置但输出随机的规则，或对市场收益去趋势。
- **Executable timing**
  - When to use: 信号使用收盘或滞后发布数据。
  - How: 信号只在数据可得后成立，并从下一可实现价格开始计收益。

## Key Concepts

- **Binary rule**: 输出两个状态；可能是多/空、多/中性或空/中性。
- **Tri-state rule**: 输出多/中性/空，允许规则只在有优势时暴露风险。
- **Traditional/inverse rule**: 规则可按传统方向或反向解释，两者必须作为不同候选登记。
- **Position bias**: 回测期间各市场状态所占比例。
- **Detrended return**: 从每期市场收益扣除样本平均收益。
- **Slippage**: 点差和订单冲击使实际成交偏离理论价格。

## Reference Formula

对于始终多空二选一的规则，无预测力基准的期望收益取决于多头概率、空头概率和市场平均变化：

```text
ER = p(long) * average_market_change - p(short) * average_market_change
```

去趋势使平均市场变化为零，因此可消除仓位偏置与市场趋势的联合作用。附录证明，这等价于从候选规则收益中扣除相同仓位偏置随机规则的期望收益。

## Worked Example

一条日线规则使用当日收盘计算输出。若回测假设以当日收盘成交，信号确认和成交使用了同一时点，发生 look-ahead bias。作者案例把当日收盘输出映射到下一日开盘成交，随后计算下一开盘到再下一开盘的收益。加密 4 小时策略应采用相同逻辑：信号 K 线结束后，使用下一可成交 tick 或下一根开盘，并明确滑点。

## Anti-patterns

- **用绝对收益评价预测力**: 上涨样本会奖励任何长期偏多规则。
- **强制永久持仓**: 可能把“偶尔出现机会”的思想歪曲为“市场永远低效”。
- **忽略数据发布日期**: 经济数据或修订数据若不按历史可得版本处理，会泄漏未来。
- **用成本前发现结果宣称可交易**: 发现信息和实现净利润是不同命题。

## Key Takeaways

1. 规则输出状态和执行映射必须与原交易主张一致。
2. 预测力评价应使用合适基准，而非只看正收益。
3. 去趋势适合隔离方向预测信息，但实际交易还要报告原始净收益。
4. 收盘信号不得获得收盘前成交。
5. 高频反转规则必须承担更高交易成本。
