# Chapter 6: Data-Mining Bias — The Fool's Gold of Objective TA

## Core Idea

数据挖掘本身可以发现更好的规则，但选择最佳观察表现会把最大正向运气一起选中；赢家仍可能是最佳候选，却不能用其样本内表现直接估计未来表现或用普通单规则 p 值评价。

## Frameworks Introduced

- **Observed performance decomposition**
  - When to use: 解读任何优化后的回测。
  - How: `observed = expected ± randomness`；搜索最大化的是两者之和。
- **Five-factor data-mining bias model**
  - When to use: 比较研究的过拟合风险。
  - How: 登记规则数、观测数、规则相关性、正向异常值和候选真实质量差异。
- **Maximum-of-N sampling distribution**
  - When to use: 从 N 个候选中挑赢家。
  - How: 在每次 H0 重采样中测试全部 N 个候选，并记录当轮最大统计量。
- **Out-of-sample and walk-forward**
  - When to use: 获得对冻结或动态再训练规则的无偏未来表现估计。
  - How: 隔离未参与选择的数据；walk-forward 只用过去训练并在随后非重叠段评价。
- **WRC and multi-rule MCP**
  - When to use: 希望利用全部历史数据进行搜索，同时校正选择偏差。
  - How: 保存全部候选的逐期信息，并重放完整搜索。

## The Five Factors

1. **规则数**：越多越容易出现极端幸运赢家。
2. **观测数**：越多，均值分布越窄、尾部越轻，偏差越小。
3. **规则收益相关性**：越低，有效独立候选越多，偏差越大。
4. **正向异常值**：大额偶然盈利会抬高赢家；更多观测可稀释。
5. **真实期望收益差异**：候选质量越相似，选择越依赖运气。

## Solution Matrix

| 方法 | 优势 | 局限 |
|---|---|---|
| 一次性 holdout | 直接、表现估计无选择偏差 | 浪费发现样本；看一次后失去纯净性 |
| Walk-forward | 适合非平稳与动态重训；产生多个样本外段 | 窗口选择任意；测试段应避免重叠 |
| Markowitz–Xu | 不需留出数据；给出收缩估计 | 近似法，可能严重失准 |
| WRC | 使用所有历史；保留规则相关结构；联合显著性 | 需保存全部规则逐期收益；原实现可能功效不足 |
| Multi-rule MCP | 公开思路；直接检验输出与未来收益配对 | 需保存全部输出；不能像 WRC 那样直接给均值置信区间 |

## Worked Example

若 12 条真实期望收益均为零的规则在噪声样本中测试，其中一条可能偶然得到 +60%。搜索程序正确地选择了观察最佳者，但 +60% 完全由运气构成。增加到更多规则会增加更极端赢家出现的概率。正确 H0 不是“最终规则均值围绕 0”，而是“12 条无效规则的最大均值分布”。

## WRC Procedure (Condensed)

1. 保存全部 N 条规则同一日期的逐期收益。
2. 将每条规则收益零中心化。
3. 每轮对日期有放回抽样，并对所有规则使用同一日期序列。
4. 计算 N 条规则的重采样均值，保留最大值。
5. 重复形成最大均值分布；以真实赢家表现计算 p 值。

## Multi-rule MCP Procedure (Condensed)

1. 保存全部 N 条规则逐期输出与市场未来收益。
2. 生成一个市场收益排列，对所有规则共享该排列以保留相关性。
3. 计算每条规则的随机配对表现并保留最大值。
4. 重复排列，形成无预测力规则宇宙的最大表现分布。

## Anti-patterns

- **只保存赢家**: 丢失联合抽样分布所需信息。
- **将参数邻域视为一次测试**: 每个查看过的候选都属于搜索。
- **重复使用测试集**: 逐步把测试集变成训练集。
- **只做普通 Bonferroni 而忽略相关结构**: 可能过度保守；交易规则常高度相关。
- **把样本内下降称为未来恶化**: 赢家未来回落通常是选择偏差的正常结果。

## Key Takeaways

1. 数据挖掘能工作，但样本内赢家表现有正偏。
2. 搜索规模必须可审计。
3. 规则间相关性决定有效候选数量。
4. 样本外数据只能保持一次性纯净。
5. 联合随机化方法必须重放完整搜索。
